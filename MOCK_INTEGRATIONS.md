# Mock Integrations

This project uses mock external integrations for academic demonstration:

- RTO/owner lookup uses local demo records instead of live VAHAN/NIC access.
- SMS and email delivery is logged in mock mode instead of contacting a paid gateway.
- Payment links in generated E-Challans are demonstration links.

These boundaries match the project scope in the report: software simulation and
implementation are included, while live government databases, paid gateways, and
physical infrastructure are outside scope.
